# Förderverein WiRe – Website

Dateien:
- index.html
- style.css
- script.js

Start:
1. Alle drei Dateien in denselben Ordner legen.
2. index.html im Browser öffnen oder in VS Code mit Live Server starten.

Hinweis:
Die Inhalte orientieren sich an den öffentlich verfügbaren Informationen des Fördervereins.
Impressum und Datenschutz sind als Platzhalter verlinkt und sollten vor einer Veröffentlichung
durch die offiziellen Seiten bzw. rechtlich erforderlichen Angaben ersetzt werden.
